# KvantumSafe Pro: Compliance Core & Post-Quantum Orchestrator 🛡️

**KvantumSafe Pro** — это высокотехнологичное постквантовое ядро безопасности (Crypto Agility Engine) корпоративного уровня. Платформа спроектирована для автоматического аудита инфраструктурных уязвимостей, защиты данных в покое (Data at Rest), а также квантово-стойкой оркестрации традиционных финтех-экосистем и децентрализованных Web3-проектов (Data in Transit).

---

## 🧭 Архитектура платформы и модульная лицензия

В данном публичном репозитории представлена открытая демонстрационная часть ядра и базовый ознакомительный модуль для ИБ-аудита внешнего периметра. Полная коммерческая версия софта поставляется в виде закрытого Enterprise-монолита (в формате автономного шлюза Proxy или компилируемой SDK библиотеки с привязкой к оборудованию закрытых серверов банка).

### 🔓 Открытые демонстрационные модули (Доступны в репозитории):
*   **`main.go`** — Бэкенд-движок управления и оркестрации веб-интерфейса платформы.
*   **`scanner.go`** (Внешний аудит) — Модуль автоматической детекции уязвимостей внешних TLS-шлюзов банков и серверов Web3.

### 🔒 Закрытые Premium-модули (Поставляются по SaaS-подписке):
*   **Продукт 2. Модуль внутреннего комплаенса серверов (`internal_fs.go`)**
    *   *Функционал:* Глубокий аудит файловых систем банка (контуры Air-Gapped). Обнаруживает открытые пароли, базы данных и уязвимые приватные ключи кошельков с автоматической изоляцией угроз (права `0600`).
*   **Продукт 3. Постквантовый крипто-мост оркестрации платежей и Web3-нод (`quantum_bridge.go`)**
    *   *Функционал:* Сквозная защита межбанковских потоков (SWIFT, XML) и транзакций блокчейн-нод. Сочетает асимметричный постквантовый стандарт **NIST ML-KEM-768** для ультра-защищенного обмена ключами в сети и суверенный высокоскоростной симметричный алгоритм КНР **GmSSL SM4-GCM** для шифрования архивов. Интегрирует режим автоматической обратной совместимости (Fallback к TLS 1.3), если у принимающей стороны не установлен модуль.
