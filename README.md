# KvantumSafe Pro: Compliance Core & Post-Quantum Orchestrator 🛡️

**KvantumSafe Pro** — это высокотехнологичное постквантовое ядро безопасности (Crypto Agility Engine) корпоративного уровня. Платформа спроектирована для автоматического аудита инфраструктурных уязвимостей банковских систем, ревизии внутренних серверов (Data at Rest) и квантово-стойкой защиты трансграничных финансовых потоков (Data in Transit).

---

## 🧭 Архитектура платформы и модульная лицензия

В данном публичном репозитории представлена открытая демонстрационная часть ядра и бесплатный модуль-приманка для ИБ-аудита внешнего периметра. Полная коммерческая версия поставляется в виде изолированного Enterprise-монолита.

### 🔓 Открытые демонстрационные модули (Доступны в репозитории):
*   **`main.go`** — Бэкенд-движок управления и оркестрации веб-интерфейса платформы.
*   **`scanner.go`** (Внешний аудит) — Модуль автоматической разведки периметра внешних шлюзов (на примере `mbank.kg`). Обнаруживает версии запущенного ПО (TLS OpenSSL Web-Gateway) и выявляет уязвимости перед атаками перехвата трафика.

### 🔒 Закрытые Premium-модули (Поставляются по SaaS-подписке):
*   **Продукт 2. Модуль внутреннего комплаенса серверов (`internal_fs.go`)**
    *   *Функционал:* Глубокий аудит файловых систем банка (включая изолированные контуры Air-Gapped). Обнаруживает забытые незашифрованные резервные копии (SQL-дампы), открытые пароли и приватные Web3-ключи (Keystore) с автоматической изоляцией угроз (права доступа `0600`).
*   **Продукт 3. Постквантовый крипто-мост оркестрации платежей (`quantum_bridge.go`)**
    *   *Функционал:* Сквозное шифрование критических потоков данных (SWIFT-переводы, трансграничные расчёты XML). Комбинирует американскую постквантовую решетчатую криптографию (**NIST ML-KEM-768**) и суверенные стандарты Китая (**GmSSL SM4-GCM**), делая трафик неуязвимым для дешифрования на квантовых компьютерах.
