# KvantumSafe Pro: Compliance Core & Post-Quantum Orchestrator 🛡️

**KvantumSafe Pro** — это высокотехнологичный программный комплекс оркестрации, маршрутизации транспортных потоков данных и постквантового контроля сетевого комплаенса корпоративного уровня. 

Платформа спроектирована для автоматического аудита инфраструктурных уязвимостей внешнего периметра, ревизии внутренних серверов (Data at Rest) и квантово-стойкой диспетчеризации традиционных финтех-экосистем и децентрализованных Web3-проектов (Data in Transit).

---

## 🧭 Архитектура платформы и модульная лицензия

В данном публичном репозитории представлена открытая демонстрационная часть ядра и базовый ознакомительный модуль для ИБ-аудита внешнего периметра. Полная коммерческая версия поставляется в виде закрытого Enterprise-монолита (в формате автономного шлюза Reverse Proxy для зоны DMЗ или компилируемой SDK-библиотеки с жесткой аппаратной привязкой к Hardware ID закрытых серверов банка).

### 🔓 Открытые демонстрационные модули (Доступны в репозитории):
*   **`main.go`** — Бэкенд-движок управления, маршрутизации запросов и оркестрации веб-интерфейса платформы.
*   **`scanner.go`** (Внешний аудит) — Автономный модуль автоматической детекции несоответствий регламентам сетевой защиты внешних TLS-шлюзов финансовых институтов и серверов Web3.

### 🔒 Закрытые Premium-модули (Поставляются по SaaS-подписке на флеш-носителях):
*   **Модуль внутреннего комплаенса серверов (`internal_fs.go`)**
    *   *Функционал:* Глубокий аудит файловых систем и Web3-инфраструктуры в изолированных контурах (Air-Gapped). Проводит энтропийный анализ и обнаруживает скрытые текстовые пароли, незащищенные базы данных и уязвимые приватные ключи валидаторов нод с автоматической принудительной изоляцией угроз (системные права доступа `0600`).
*   **Постквантовый крипто-мост и диспетчер платежных шлюзов (`quantum_bridge.go`)**
    *   *Функционал:* Сквозная оркестрация и защита межбанковских потоков (SWIFT, XML) и транзакций блокчейн-нод. Инициирует вызов асимметричного постквантового стандарта **NIST ML-KEM-768** для ультра-защищенного обмена ключами в сети и суверенного высокоскоростной алгоритма КНР **GmSSL SM4-GCM** на аппаратном уровне встроенных HSM-модулей банка. Интегрирует режим интеллектуальной обратной совместимости (Fallback к TLS 1.3), если у принимающей стороны не установлено ядро платформы.

## 🔒 Безопасность и комплаенс кода (SAST Audit)

Кодовая база ядра платформы успешно прошла строгую ИБ-верификацию официальным статическим сканером уязвимостей **Gosec (Go Security Assistant)** по международной классификации CWE (Common Weakness Exclusion). Внедрение скрытых учетных записей или уязвимостей переполнения буфера полностью исключено.

