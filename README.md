## 🔍 О проекте (Open Source Контур)
В данном публичном репозитории представлена открытая демонстрационная часть платформы **KvantumSafe**. Модуль предназначен для автоматизированного экспресс-аудита уязвимостей внешнего сетевого периметра и проверки конфигурации TLS-шлюзов финансовых организаций.

### Доступные компоненты в репозитории:
*   **main.go** — Управляющий веб-сервер, маршрутизация входящих запросов и оркестрация пользовательского интерфейса.
*   **scanner.go** — Сетевой движок бесконтактного сканирования, осуществляющий автоматическую детекцию параметров безопасности внешних узлов.
*   **views.go** — Архитектура веб-интерфейса, спецификаций и Маркетплейса решений.
